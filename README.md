# Лендинг детейлинг-центра

Адаптивный коммерческий лендинг с интерактивным каталогом услуг, слайдером «до/после» и галереей работ. Проект разработан с акцентом на высокую скорость загрузки, семантическую верстку и чистую архитектуру стилей.

🔗 **Живое демо:** [https://sentawolf.github.io/detailing-site/](https://sentawolf.github.io/detailing-site/)

## 🛠 Технологический стек
* **Разметка:** Семантический HTML5, SVG-спрайты
* **Стили:** SCSS (модульная структура, миксины, переменные, адаптив)
* **Скрипты:** Vanilla JavaScript (ES6+), библиотека масок ввода `IMask`, анимации `GSAP`
* **Сборка:** Vite (PostCSS, Autoprefixer, оптимизация ассетов)
* **CMS-интеграция:** Проект также адаптирован под **GravCMS** (шаблонизатор Twig, кастомные поля и блюпринты для управления контентом из админ-панели)

## ✨ Реализованный функционал
* Интерактивный слайдер сравнения фотографий «До / После» в карточках кейсов
* Динамическая фильтрация каталога услуг по категориям без перезагрузки страницы
* Модальные окна с подробным описанием услуг, кейсов и отзывов
* Валидация форм обратной связи и маска для номера телефона
* Полная адаптивность под десктопные, планшетные и мобильные устройства

## 🚀 Локальный запуск проекта
1. Клонировать репозиторий: `git clone https://sentawolf.github.com/detailing-site/`
2. Установить зависимости: `npm install`
3. Запустить сервер для разработки: `npm run dev`
4. Собрать проект в продакшн: `npm run build`
